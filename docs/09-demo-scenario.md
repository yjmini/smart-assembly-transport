# 09. 데모 시나리오

## 목표

5분 내외로 “음성 명령 → 조립 → 배송 → 완료 보고”와 “손 감지 비상 정지 → 관리자 복구”를 명확하게 보여준다.

## 기본 시나리오

1. Dashboard 초기 화면과 장비 대기 상태를 보여준다.
2. 작업자가 “제품 조립 후 A구역으로 배송해”라고 말한다.
3. Dashboard에 작업 오더가 생성된다.
4. 컨베이어가 베이스 부품을 이동한다.
5. 비전이 베이스 부품 정위치 도달을 감지하고 컨베이어가 정지한다.
6. Dobot이 1단계/2단계 조립을 수행한다.
7. 비전이 완성품을 확인한다.
8. Dobot이 TurtleBot 적재함에 제품을 올린다.
9. TurtleBot이 A구역으로 이동한다.
10. TurtleBot이 배송 완료를 보고한다.
11. TurtleBot이 시작 위치 또는 대기 위치로 복귀한다.
12. TTS와 Dashboard가 복귀 완료 및 다음 작업 대기 상태를 알린다.

## 안전 시나리오

1. 공정 중 카메라 영역에 손을 넣는 상황을 연출한다.
2. Vision Detector가 `HAND_DETECTED` 이벤트를 발생시킨다.
3. 컨베이어와 Dobot이 즉시 정지한다.
4. Dashboard에 비상 정지 모달이 표시된다.
5. 관리자 비밀번호 입력 후 공정을 복구한다.
6. 공정이 재개되거나 안전 재시작된다.

## 촬영 포인트

- 전체 장비 배치 1컷
- Dashboard 상태 변화 1컷
- 컨베이어 정지 순간 1컷
- Dobot 조립 장면 1컷
- TurtleBot 배송 장면 1컷
- 비상 정지/복구 장면 1컷

## fallback 데모

실제 장비 일부가 실패하면 다음 순서로 대체한다.

- 컨베이어 실패: mock conveyor 로그 + 수동 이동 영상
- Vision 실패: 저장 영상 또는 샘플 이미지 추론
- Dobot 실패: 고정 좌표 단품 영상 + mock action result
- TurtleBot 실패: RViz/Nav2 시뮬레이션 또는 기존 주행 영상
- STT 실패: Dashboard 수동 오더 입력
