# 01. 프로젝트 개요

## 한 줄 정의

작업자의 음성 명령을 시작점으로 컨베이어, 비전, Dobot 로봇팔, TurtleBot을 연동하여 자동 조립과 무인 배송을 수행하는 스마트팩토리 통합 시스템.

## 배경 및 목표

본 프로젝트는 임베디드 로봇 트랙에서 학습한 ROS 2, 비전, 로봇팔 제어, 모바일 로봇 자율주행, 웹 모니터링, 음성 인터페이스 기술을 하나의 공정으로 통합하는 것을 목표로 한다.

핵심 목표는 다음과 같다.

- STT를 통해 작업자의 자연어 명령을 작업 오더로 변환
- 컨베이어 위 부품을 비전으로 감지하고 조립 위치에서 정지
- Dobot 로봇팔로 다단계 조립 수행
- 비전 기반 품질 확인 후 정상 제품을 TurtleBot에 적재
- TurtleBot이 지정 목적지까지 자율 배송
- 사람 손 감지 시 즉시 비상 정지하고 관리자 승인 후 복구
- 대시보드와 TTS로 공정 상태를 사용자에게 전달

## 시스템 동작 요약

1. 작업자가 “제품 조립 후 A구역으로 배송해”와 같은 명령을 말한다.
2. STT 모듈이 음성을 텍스트로 변환하고 작업 오더를 생성한다.
3. Mission Orchestrator가 공정 FSM을 시작한다.
4. 컨베이어가 베이스 부품을 이송한다.
5. 카메라가 베이스 부품의 정위치 도달을 감지하면 컨베이어를 정지한다.
6. Dobot이 1단계, 2단계 부품을 조립한다.
7. 비전 모듈이 완성품 상태를 확인한다.
8. Dobot이 정상 제품을 TurtleBot 적재함에 올린다.
9. TurtleBot이 Nav2 goal을 받아 목적지까지 이동한다.
10. 도착 후 TTS와 Dashboard로 완료 상태를 보고한다.

## 범위

### MVP에 포함

- 작업 오더 생성 및 공정 상태 관리
- ROS 2 기반 Mission Orchestrator FSM
- 컨베이어 start/stop 인터페이스
- 베이스 부품/손/완성품 감지 이벤트
- Dobot pick/place 조립 루틴
- TurtleBot Nav2 배송 goal 전송
- 비상 정지 및 관리자 복구 흐름
- 대시보드 상태 표시

### MVP에서 제외하거나 후순위

- 고정밀 다품종 조립 모델
- 완성도 높은 통계/관리자 시스템
- 실제 산업 안전 인증 수준 검증
- 클라우드 배포 및 사용자 계정 관리
- 장기 운영을 위한 장애 복구 자동화

## 운영 원칙

- **안전 우선**: 손 감지, STOP, 관리자 복구는 공정 기능보다 우선한다.
- **인터페이스 우선**: ROS 2 topic/action/service와 WebSocket 메시지를 먼저 합의한다.
- **점진적 통합**: mock → 단품 real node → 통합 real node 순서로 진행한다.
- **데모 가능성 유지**: 장비 실패 시 mock fallback으로 전체 흐름을 설명할 수 있어야 한다.
